# AIXORA Website

Static one-page website for AIXORA / AIXO.

## Deploy on GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` and the `assets` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will publish the site.

## Important project note

The 2,000,000 AIXO daily purchase limit and wallet blocking language on the site are presented as the project's intended token policy. A static website cannot enforce blockchain rules. To make the limit and address-blocking mechanism real, the smart contract must implement those controls and should be independently audited before being represented as active.

The PancakeSwap button points directly to the supplied AIXO/BNB swap URL.
